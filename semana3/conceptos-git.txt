conceptos:
Pregunta 7:

Repositorio: Un repositorio es el lugar donde Git guarda los archivos de un proyecto y todo su historial de cambios. Sirve para organizar el trabajo y poder volver a versiones anteriores cuando sea necesario.

Commit: Un commit es un registro guardado de los cambios hechos en el proyecto. Funciona como una “foto” del estado actual del código, con un mensaje que explica qué se modificó.

Push: Push es el comando que envía los cambios guardados en tu computadora a un repositorio remoto. Se usa para subir tu trabajo a plataformas como GitHub y compartirlo con otras personas.
