Pregunta 1: ¿Que es una ruta (route) en Express?
Respuesta: b. Una dirección que define cómo responde el servidor a una solicitud

Pregunta 2: ¿Qué método HTTP se usa normalmente para consultar información?
Respuesta: b. GET

Pregunta 3: ¿Qué método HTTP se usa normalmente para enviar o registrar información?
Respuesta: a. POST

Pregunta 4: ¿Qué significa API?
Respuesta: b. Interfaz que permite que sistemas o aplicaciones se comuniquen entre sí
